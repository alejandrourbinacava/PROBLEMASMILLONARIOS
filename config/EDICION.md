# Doctrina de edición — Problemas Millonarios

Este documento manda sobre cualquier decisión de montaje del pipeline. Si algo
que produce el código contradice esto, el fallo es del código.

## La regla

**Editar el significado, no el audio.**

La pregunta no es «¿qué imagen pongo aquí?». Es «¿cómo visualizo lo que acaba de
decir el narrador?».

Prueba de fuego: el espectador tiene que poder entender la información aunque
viera unos segundos sin sonido.

## Lo que esto prohíbe

- Pasar imágenes cada 5-10 segundos
- Metraje de archivo con zoom lento como recurso por defecto
- Un clip que solo *acompaña* a la frase en vez de explicarla
- Subtítulos permanentes
- Transiciones genéricas iguales entre todos los planos
- Efectos porque sí: cada animación tiene función narrativa o sobra
- La misma plantilla para todas las escenas

## Vocabulario de recursos

Cada frase del guion se resuelve eligiendo el recurso que MEJOR la explica, no
el que toque por turno:

| Recurso | Cuándo |
|---|---|
| cifra animada | se dice un número que importa |
| comparación | dos cantidades cuya diferencia es el argumento |
| desglose | una cuenta que se va sumando partida a partida |
| mapa | se menciona un sitio: localizar, acercar, señalar |
| recorte + etiqueta + flecha | hay que señalar algo dentro de una imagen |
| documento | hay una fuente que enseñar, con zoom a la cifra |
| escena por capas | un momento con peso, con moderación |
| detalle de archivo | contexto, plano corto |
| tarjeta de texto | un concepto o una conclusión |

## Ritmo

El estímulo visual cambia cada 2-5 segundos **cuando el contenido lo permite**.
Un plano puede durar 7 segundos si se está explicando algo. La duración la manda
la información, nunca el cronómetro.

## Las cifras

Son la identidad del canal. Cuando se dice una cantidad importante se convierte
en elemento visual: la cifra, su etiqueta, y una animación breve. Cuando hay
comparación, la diferencia tiene que verse, no deducirse.

## Las transiciones

Salen de la propia información. El gráfico de ingresos se desplaza y revela el
de costes. La transición es parte de la explicación, no un adorno entre dos
planos.

## Para cada bloque del guion

1. ¿Qué está diciendo?
2. ¿Cuál es la idea principal?
3. ¿Qué recurso la representa mejor?
4. ¿Qué elemento debe llamar la atención?
5. ¿Cuánto tiene que permanecer?
6. ¿Qué transición conecta con lo siguiente?

## Identidad

Documental + negocios + economía + investigación. La sensación final tiene que
ser: «ahora entiendo cómo funciona económicamente este negocio».

Se toman los principios de VOX (explicación editorial), MagnatesMedia (cifras y
relato empresarial) y Parallax (capas y profundidad sutil). No se copia a
ninguno.
